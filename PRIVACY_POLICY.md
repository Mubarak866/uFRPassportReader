# Privacy Policy - µFR Passport Reader

**Last Updated**: July 12, 2026

## Overview

µFR Passport Reader is committed to protecting your privacy. This Privacy Policy explains how our application handles your data and personal information.

## Key Privacy Principles

### ✅ What We Do NOT Do

- **NO Data Collection**: We do NOT collect any personal information
- **NO Data Storage**: We do NOT store data on external servers
- **NO Tracking**: We do NOT track user behavior or activities
- **NO Analytics**: We do NOT use analytics services
- **NO Third-Party Sharing**: We do NOT share data with any third parties
- **NO Advertisements**: We do NOT display personalized advertisements

### ✅ What We DO Do

- **Local Processing Only**: All data processing happens on your device only
- **Automatic Deletion**: All data is automatically deleted when you close the app
- **User Control**: You have explicit control over data transmission
- **Transparent**: No hidden data collection or secret logging

## Data Handling

### When You Use the App

1. **NFC Chip Reading**
   - Data is read directly from the passport's NFC chip
   - Data is loaded into your device's memory only
   - Data remains on your device unless you explicitly send it

2. **OCR Processing**
   - Images from your camera are processed locally on your device
   - OCR results are stored temporarily in device memory
   - No images are saved or transmitted without your permission

3. **Personal Data**
   - Any extracted personal data stays on your device
   - Data is never saved to permanent storage
   - Data is never transmitted without explicit user action

4. **Optional Upload**
   - Data transmission ONLY occurs if you enable the "Send data automatically after reading" option
   - You can configure the destination server
   - Transmission requires internet connection
   - You can disable this feature at any time

## Data Lifecycle

```
Step 1: Read NFC Chip
└─ Data loaded into device RAM

Step 2: Display Information
└─ User reviews data on screen

Step 3: Choose Action
├─ Option A: Close app → Data automatically deleted
└─ Option B: Send to server → Data transmitted only if enabled

Step 4: Close Application
└─ ALL remaining data permanently deleted from memory
```

## Your Rights & Control

### Settings Available to You

- ☑️ Enable/Disable: Read personal data
- ☑️ Enable/Disable: Extract picture
- ☑️ Enable/Disable: Check document validity
- ☑️ Enable/Disable: Send data automatically after reading
- 🔗 Configure: Server URL for data transmission

### You Can

- Change these settings at any time
- Refuse to transmit data
- Use the app completely offline
- Manually review all data before any transmission
- Delete the app and remove all associated data

## Technical Security

### Data Protection

- All communication uses secure protocols
- NFC chip reading is encrypted by the device
- Optional data transmission can use HTTPS

### No Persistence

- No local database storing personal data
- No cache files containing sensitive information
- No backup files created by the app
- Complete memory clearing on app termination
